DOUBLE — Privacy Policy

Effective date: November 7, 2026

Summary: DOUBLE does not require an account, does not contain advertising, and does not intentionally collect, sell, or share personal information.

Information stored on your device

DOUBLE may store game preferences, selected settings, local statistics, best scores, daily challenge progress, and similar gameplay data using local browser/app storage. This information is stored locally on your device and is used to keep your settings and progress between sessions.

Internet access

The Android app uses an internet connection to load the DOUBLE game files from the developer's GitHub Pages site. The app does not use analytics SDKs, advertising SDKs, Firebase, Supabase, or a user-account system.

Server and hosting data

When the app loads web content, the hosting provider may process routine technical request information such as IP address, browser or device information, and request timestamps as part of normal web hosting and security operations. That processing is governed by the hosting provider's own policies.

Children

DOUBLE does not ask users to provide a name, email address, phone number, precise location, or other personal profile information. The game is designed to function without creating a user account.

Data sharing and sale

DOUBLE does not sell personal data and does not intentionally share gameplay data with advertisers or data brokers.

Permissions

The Android app requests internet access to load the game and may use device vibration/haptic feedback for gameplay. It does not request contacts, camera, microphone, precise location, SMS, or storage/media permissions.

Changes to this policy

If DOUBLE later adds online accounts, analytics, advertising, cloud saves, multiplayer networking, or other features that change data handling, this policy and the Google Play Data safety declaration will be updated before release.

Contact

Questions about this policy can be submitted through the project's public repository: GitHub Issues.
