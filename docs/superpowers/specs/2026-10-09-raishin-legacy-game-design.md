# מורשת ראיישין — משחק עצמאי

## מטרה
לבנות את **מורשת ראיישין** כמוצר משחק עצמאי, שאינו חלק מעמודי "עולם ראיקה" ואינו תלוי ב־`raika.html`, ב־CSS שלו או בקוד שלו. הגרסה הראשונה נועדה לפתוח כתובת עצמאית למשחק ולהציג את מסך ה־Gameplay המאושר של ראיקה בדוג'ו כבסיס שעליו נפתח תנועה, אינטראקציה ולחימה.

## גבולות גרסה 0.1
- אתר/אפליקציה עצמאית תחת נתיב ייעודי: `raishin-legacy/`.
- `index.html`, `styles.css`, `game.js` ו־`assets/` ייעודיים למשחק בלבד.
- אין קישור תלות ל־`raika.html`, `raika-*.js`, `raika-*.css` או למערכות הפיד של האתר הראשי.
- מסך הפתיחה הוא **מסך ה־Gameplay המאושר**: ראיקה מאחור בתוך Inazuma Dojo עם HUD מינימלי.
- HUD v0.1: חיים, Raihatsu/אנרגיה, מטרה נוכחית, Jump, Dodge, Interact ומינימאפ קטן.
- אין עדיין מערכת קרב, inventory, skill tree, NPCs או שמירה.

## Visual Lock — ראיקה
בכל נכס או מסך שבו ראיקה מופיעה:
- משתמשים ב־Front Lock וב־Back Gameplay Lock המאושרים כרפרנס מחייב.
- אין אוזניים אנושיות כלל — גם לא מוסתרות או מרומזות.
- רק שתי אוזני ארנבת קאנוניות.
- השיער מכסה את צדי הראש והלחיים.
- אין שינוי בפנים, עיניים, שיער, קוקו, סרט ירוק, לבוש אימונים, פרופורציות או מבנה גוף.
- אין זנב.
- תמונה שסוטה מאחד החוקים האלה פסולה ואינה הופכת לרפרנס המשך.

## Visual Lock — Inazuma Dojo
הדוג'ו נשאר לפי הרפרנסים המאושרים של פנים וחוץ הדוג'ו. בגרסה 0.1 מוצג האולם הפנימי בלבד. אין יצירה מחדש של סגנון, מבנה או פריסת האולם בזמן הטמעת ה־Gameplay.

## מבנה טכני
המשחק יישאר בתוך אותו Repository לצורך פרסום פשוט דרך GitHub Pages, אבל יהיה מבודד בתוך תיקייה משלו:

```text
raishin-legacy/
  index.html
  styles.css
  game.js
  assets/
    gameplay/
    characters/
    dojo/
```

הבידוד הוא ברמת הקוד והנכסים: שינוי במשחק לא אמור לשנות עמודים אחרים באתר, ושינוי באתר הראשי לא אמור לשבור את המשחק.

## התנהגות גרסה 0.1
1. פתיחת הכתובת מציגה מסך משחק מלא/כמעט מלא עם יחס 16:9.
2. השוט המאושר הוא הרקע והעוגן החזותי.
3. רכיבי HUD נשארים קריאים בדסקטופ ובמובייל ואינם מסתירים את ראיקה.
4. בגרסה הראשונה הכפתורים יכולים להיות UI בלבד; מכניקת התנועה תיכנס במיילסטון הבא.
5. אין ניווט חזרה ל"עולם ראיקה" מתוך מסך המשחק עצמו, כדי לשמור על תחושת מוצר עצמאי.

## רספונסיביות
- Desktop: מסך 16:9 ממורכז, עדיפות למילוי רוחב תוך שמירת כל השוט.
- Mobile landscape: המשחק ממלא את רוב המסך.
- Mobile portrait: השוט נשמר במלואו; HUD מצטמצם בלי לחתוך את ראיקה.

## בדיקות קבלה לגרסה 0.1
- הכתובת העצמאית נפתחת ללא תלות ב־`raika.html`.
- אין 404 לקבצי CSS/JS/Assets של המשחק.
- המסך המאושר מוצג ביחס נכון וללא מתיחה.
- HUD אינו מכסה את ראיקה.
- טעינת המשחק אינה משנה את ה־DOM או ה־CSS של האתר הראשי.
- אין import או reference לקבצי Raika הראשיים.
- בדיקת מובייל ודסקטופ עוברת ללא גלילה אופקית לא רצויה.

## המיילסטון הבא
לאחר אישור גרסה 0.1 עוברים ל־**Movement Prototype**: Idle → Walk → Jog/Sprint → Turn → Stop, ולאחר מכן Jump → Dodge → Interact. כל שלב יפותח בנפרד ויעבור QA מול ה־Visual Lock לפני מעבר לשלב הבא.
