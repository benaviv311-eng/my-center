# Book Reels — Design Specification

Date: 2026-09-21  
Project: המרכז שלי / my-center  
Scope: ספרייה בלבד בשלב הראשון, עם ארכיטקטורה שניתנת להרחבה בהמשך לכדורעף, מאמן, ראיקה, שפות ומוזיקה.

## 1. מטרת המערכת

Book Reels היא שכבת וידאו אנכית מעל ספריית הלמידה הקיימת.

המטרה היא להפוך חומר שכבר קיים בספרייה — רעיונות, משפטים קצרים, תיאוריות, דוגמאות, יישומים ושאלות — לרילסים קצרים, ברורים ואסתטיים, עם:

- גרפיקה 9:16.
- קריינות טבעית בעברית.
- טקסט מסונכרן לקריינות.
- Visual שמתאים לרעיון.
- קישור חזרה לספר ולפריט המקורי.
- פעולות שמור / יותר כזה / פחות כזה.
- אפשרות לייצר כמה וריאציות לאותו מקור.

הספרייה נשארת מקור האמת. המערכת לא משכפלת את תוכן הספרים לבנק תוכן שני.

## 2. עקרון מקור-אמת

כל Reel נוצר מתוך פריט קיים בספרייה.

הקשר נשמר כך:

bookId -> sourceItemId -> reelId

ה-Reel שומר רק את מה שנדרש להצגת הסרטון:

- hook
- voiceText
- screenText
- visual reference/prompt
- template
- audio
- timings
- metadata

הטקסט המקורי של הספר, הרעיון, התיאוריה או היישום ממשיכים לחיות במערכת הספרייה.

## 3. מקורות תוכן מותרים

המנוע יכול ליצור Reel מתוך:

1. קטע קצר או משפט קצר מתוך חומר הספר.
2. רעיון מרכזי מהספר.
3. תקציר או פרפרזה.
4. תיאוריה מקצועית שמקושרת לספר.
5. פסיכולוגיה / גישה / היבט נוסף.
6. דוגמה מהיום-יום.
7. יישום מעשי.
8. דוגמה מהחיים.
9. שאלה למחשבה.
10. מושג מקצועי קשור מתוך מערכת LibraryDiscovery.

## 4. כללי זכויות יוצרים

אם המקור מוגן בזכויות יוצרים:

- ציטוט מדויק יהיה קצר.
- אין להקריא קטעים ארוכים מתוך ספר מוגן.
- Reel ארוך יותר יתבסס על פרפרזה, הסבר או יישום.
- כל Reel יסומן לפי סוג המקור:
  - "ציטוט מהספר"
  - "רעיון מתוך הספר"
  - "הרחבה מקצועית"
  - "פרפרזה / הסבר"
- אין להציג פרשנות של המערכת כאילו היא דברי המחבר.

## 5. מבנה Reel בסיסי

פורמט: 9:16  
משך יעד: 15–30 שניות  
מצב: מסך מלא, גלילה אנכית.

מבנה ברירת מחדל:

1. Hook — 1–3 שניות.
2. משפט / רעיון מרכזי.
3. הסבר קצר או דוגמה.
4. מסר אחד לקחת הלאה.
5. Attribution לספר.
6. CTA: "פתח את הספר".

ה-Reel חייב להיות מובן גם כשהקול כבוי.

## 6. Templates

### 6.1 Cinematic Quote

- Visual מלא מסך.
- משפט קצר ומרכזי.
- טקסט נכנס לפי קצב הקריינות.
- שם הספר מופיע בסיום.

### 6.2 Kinetic Typography

- הטקסט הוא האלמנט הראשי.
- מילים נעות, גדלות, מתחלפות או נשברות לפי משמעות.
- מתאים למשפטים חזקים ולרעיונות קצרים.

### 6.3 Idea -> Example

- חלק ראשון: הרעיון.
- חלק שני: המחשה מהחיים.
- סיום: takeaway.

### 6.4 Question Reel

- שאלה קצרה בתחילת הסרטון.
- השהיה קצרה.
- תשובה / רעיון מהספר.
- אפשרות בעתיד לכפתורי בחירה אינטראקטיביים.

### 6.5 One Thing Today

- רעיון מעשי אחד.
- ניסוח קצר.
- CTA לביצוע היום.

## 7. קריינות

ברירת המחדל:

- עברית טבעית.
- קול רגוע, ברור ובוגר.
- לא דרמטי מדי.
- מהירות שמתאימה לקריאה יחד עם הטקסט.

המערכת תשמור word timings או segment timings כדי לסנכרן את הכתוב על המסך.

מצבי קול עתידיים:

- רגוע
- לימודי
- דרמטי
- אנרגטי

המשתמש יכול להשתיק או להפעיל קול.

## 8. Visuals

ה-Visual צריך להיות קשור למשמעות, לא רק "יפה".

דוגמאות:

- הרגל -> פעולה שחוזרת על עצמה.
- פחד מכישלון -> רגע לפני החלטה.
- מנהיגות -> קבוצה ואדם שמוביל.
- עומס קוגניטיבי -> עודף גירויים / משימות.
- שקט -> סצנה איטית, נקייה, מינימליסטית.

אם אין וידאו מתאים:

- משתמשים בתמונה איכותית.
- מוסיפים תנועת מצלמה עדינה.
- לא משתמשים בווידאו לא קשור רק כדי "למלא רקע".

## 9. רמות מדיה

### Level 1 — Auto Graphic

- רקע גרפי.
- טקסט מונפש.
- קריינות.
- ללא צורך בנכס וידאו חיצוני.

### Level 2 — Visual Reel

- תמונה או רצף תמונות.
- Pan/zoom עדין.
- טקסט וקריינות.

### Level 3 — Premium Reel

- סרטון אמיתי, אנימציה או וידאו שנוצר במיוחד.
- משמש רק לרילסים נבחרים.

כל מקור חייב להיות מסוגל לעבוד לפחות ברמה 1.

## 10. מסך Reels בספרייה

בספרייה יתווסף כפתור:

▶ Reels

המסך:

- Fullscreen.
- 9:16.
- swipe למעלה = הבא.
- swipe למטה = הקודם.
- tap = play/pause.

פעולות:

- ❤️ שמור
- ＋ יותר כזה
- － פחות כזה
- 🔊 קול
- ⋯ אפשרויות
- 📖 פתח את הספר

לחיצה על שם הספר או CTA פותחת את הספר הרלוונטי, לא את דף הספרייה הכללי.

## 11. Reels בתוך ספר

בפתיחת ספר בודד:

- ▶ צפה ברילסים של הספר
- 🎲 Reel אקראי

במצב זה הפיד מסונן ל-bookId הנוכחי.

## 13. למידה מהעדפות המשתמש

המערכת תשתמש באותות:

- save
- more-like-this
- less-like-this
- completion
- skip speed
- replay

אבל לא תבנה בועה מוחלטת.

יש לשמור מינון של discovery:

- מדי פעם Reel מנושא או ספר שלא נבחר לאחרונה.
- אין להסיר לחלוטין תחומים רק בגלל מספר דילוגים.

## 14. Reel Generator

לכל פריט מתאים בספרייה ניתן יהיה להוסיף:

✨ צור Reel מהפריט הזה

מצבים:

- אוטומטי
- יותר דרמטי
- יותר לימודי
- קצר יותר
- שנה Visual
- שנה קול
- צור עוד גרסה

המערכת מייצרת וריאציה חדשה אך משאירה את sourceItemId המקורי.

## 15. סטטוסים

לכל Reel:

- draft
- approved
- active
- archived

MVP אינו מפרסם אוטומטית כל Reel שנוצר.

ברירת מחדל:

generated -> draft

רק approved/active נכנסים לפיד הראשי.

בעתיד ניתן להוסיף Auto Approval לפי בדיקות איכות.

## 17. רכיבי מערכת

### 17.1 Reel Source Adapter

אחראי להמיר פריטי ספרייה קיימים לפורמט מקור אחיד.

תלוי ב:
- library payload
- LibraryDiscovery

לא מייצר וידאו.

### 17.2 Reel Script Builder

מייצר:

- hook
- voiceText
- screenText
- source attribution
- takeaway

### 17.3 Reel Template Renderer

מקבל script + template + visual.

אחראי להצגה בדפדפן.

### 17.4 Voice Layer

אחראי על:

- narration asset
- timings
- mute/unmute

### 17.5 Reel Feed Controller

אחראי על:

- ordering
- filters
- vertical navigation
- preloading
- completion
- saved/more/less

### 17.6 Reel Generator UI

אחראי על יצירת Reel מתוך פריט ספרייה.

### 17.7 Reel Store

אחראי על:

- reel metadata
- status
- source links
- user interactions

## 18. ביצועים

- אין לטעון את כל ה-Reels בבת אחת.
- prefetch רק ל-Reel הנוכחי, הבא והקודם.
- תמונות/וידאו נטענים lazy.
- audio נטען סמוך להצגה.
- יש fallback לרמה 1 כאשר media asset חסר.
- הפיד חייב לעבוד גם בחיבור חלש.

## 19. נגישות

- כתוביות תמיד זמינות.
- אפשרות mute/unmute.
- contrast גבוה מספיק לטקסט.
- אין להסתמך רק על צבע.
- כפתורים כוללים aria-label.
- תמונות כוללות alt מתאים.
- prefers-reduced-motion יפחית אנימציות.

## 20. שגיאות ו-Fallback

אם narration חסרה:
- Reel מוצג עם טקסט בלבד.

אם visual חסר:
- עובר אוטומטית ל-Auto Graphic.

אם source item נמחק:
- Reel מסומן orphaned ולא מוצג עד טיפול.

אם asset לא נטען:
- לא חוסמים את הפיד.

## 21. MVP

הגרסה הראשונה כוללת רק:

1. Reel adapter לספרייה.
2. Reel script model.
3. שלושה templates ראשונים:
   - Cinematic Quote
   - Kinetic Typography
   - Idea -> Example
4. מסך Reels אנכי בספרייה.
5. Reels בתוך ספר בודד.
6. save / more / less.
7. open-book deep link.
8. narration-ready data model.
9. fallback text+graphics.
10. Reel Generator בסיסי מתוך פריט ספרייה.
11. draft / approved / active.
12. tests למקור, mapping, feed ו-deep-linking.

לא ב-MVP:

- תגובות.
- עוקבים.
- פרופילים חברתיים.
- עריכת וידאו מלאה.
- timeline editor.
- פילטרים חזותיים מורכבים.
- מערכת פרסום לרשתות חברתיות.
- יצירת וידאו Premium אוטומטית לכל פריט.

## 22. הרחבה עתידית לשאר האתר

המנוע נבנה כ-Reels Core משותף.

בהמשך כל עולם יוסיף adapter ו-templates משלו:

- כדורעף: תרגילים, טכניקה, טעויות, שחקני על.
- מאמן: מחקר, פסיכולוגיה, שפת אימון.
- ראיקה: סצנות, ציטוטים, קונפליקטים.
- שפות: מילים, הגייה, משפטים, שאלות.
- מוזיקה: תרגילים, פראזות, תיאוריה.

אין לבנות מנוע Reel חדש לכל עמוד.

## 23. קריטריוני הצלחה

ה-MVP נחשב מוצלח כאשר:

1. אפשר לפתוח מסך Reels מתוך הספרייה.
2. כל Reel יודע מאיזה bookId ו-sourceItemId הגיע.
3. אפשר לעבור אנכית בין רילסים ללא רענון עמוד.
4. Reel מציג hook, תוכן, attribution ו-CTA.
5. "פתח את הספר" מוביל לספר המקורי.
6. Reel נשאר מובן בלי קול.
7. save/more/less נשמרים.
8. Reel ללא media asset עדיין עובד.
9. ספר בודד יכול להציג רק את ה-Reels שלו.
10. הארכיטקטורה לא משכפלת את מאגר הספרייה.

## 24. עקרון מנחה

Book Reels היא דרך נוספת לצרוך את אותו ידע — לא ספרייה שנייה.

המערכת צריכה לגרום למשתמש לעצור, להבין רעיון אחד במהירות, ואז לאפשר לו להעמיק במקור.
